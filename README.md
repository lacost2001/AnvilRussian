## Установка

**Для установки на непроверенные сборки один раз скачайте новый `AnvilRussian.exe` из выпуска 1.6.0 или новее.** Старые патчеры обновляют данные перевода, но не собственную программу, поэтому новый режим в них автоматически не появится.

1. Закройте игру.
2. Распакуйте архив и запустите `AnvilRussian.exe`.
3. Выберите папку `Anvil Playtest`, нажмите **Установить / обновить**.
4. Если сборка не проверена, прочитайте предупреждение. Нажмите **Да**, чтобы установить перевод всё равно, или **Нет**, чтобы оставить файлы без изменений.
5. Запускайте игру через Steam.

Проверенная сборка игры: **Steam build 26953505**; совместимость определяется отпечатками файлов, а не только номером. На других сборках установка разрешена после отдельного подтверждения. Патчер показывает предупреждение: перевод ещё не проверен для этой версии, некоторые тексты могут остаться на английском или устареть; возможны ошибки отображения и работы игры. Это разрешение на установку, а не гарантия совместимости со всеми будущими сборками.

Перевод не заявляется полным: отдельные названия, динамические сообщения и варианты общих ключей ещё могут оставаться английскими. Полный визуальный проход по новой сборке не выполнен. Присылайте скриншоты через Issues или Discord.

## Обновления

При каждом запуске патчер проверяет последний стабильный GitHub Release. Для уже установленного перевода совместимое обновление скачивается и устанавливается автоматически, если игра закрыта. Если новый пакет не проверен для вашей игры, патчер предложит установить его вручную с предупреждением. Без подтверждения текущие файлы остаются на месте. Когда появится совместимый выпуск, автоматическая установка снова сработает. При первом запуске установка выполняется кнопкой. Есть отдельная кнопка проверки GitHub.

Для проверки обновлений запускайте **патчер**. Постоянного фонового сервиса нет; запуск игры непосредственно из Steam проверку не запускает.

Обновляется пакет перевода, а не программа-патчер. Проверяются версия, SHA-256 каждого файла, размер и отпечаток архива игры, SHA-256 игрового EXE. Пакет содержит только три вида ресурсов, пути установки заданы в программе. Отказ от строгой совместимости действует только для явно подтверждённой ручной установки: автоматические обновления её не обходят. При проблемах сети доступен встроенный перевод; уже загруженная и установленная версия сохраняется для работы без сети. Предупреждение о непроверенной сборке сохраняется и после перезапуска.

Даже в этом режиме нельзя установить перевод в папку без игры, поверх неполных основных файлов или поверх чужих и вручную изменённых файлов перевода. Повреждённые пакеты обновлений отклоняются. Удаление перевода доступно и на непроверенной сборке.

Обновление самой игры **не создаёт перевод автоматически**: автор должен проверить новую сборку, обновить строки и опубликовать совместимый выпуск. После изменения формата патчера новую программу потребуется скачать из Releases вручную.

Для удаления используйте кнопку **Удалить перевод**. Основной архив и EXE игры не изменяются. Изменённые вручную файлы локализации защищены от перезаписи. Источник обновлений — только Releases этого репозитория; независимая цифровая подпись пакетов пока не используется.

## Сборка и выпуск новой версии

Исходники сборки находятся в корне. Нужны Windows, Python 3 и .NET Framework 4.x (для игроков они отдельно не требуются).

```powershell
.\build.ps1
```

Результат — `dist/AnvilRussian.zip`, `dist/AnvilRussian.exe`, `dist/translation.xml`. Сборка проверяет подстановки и выполняет проверки установки, обновления, удаления, повреждённых пакетов и несовместимой игры.

1. В `translations.json` измените поле `russian`; сохраните `namespace`, `key`, исходный `source`, все `{0}` и теги разметки.
   Названия из `original-map-names.json` должны совпадать с оригиналом. Сборка проверяет их по ключам, чтобы одноимённые предметы продолжали переводиться. При обновлении игры сопоставьте и дополните этот список.
2. Увеличьте `version` в `release-config.json`. Для новой игры сначала заново извлеките и проверьте строки, затем обновите отпечатки игры. **Не меняйте отпечатки лишь для обхода проверки совместимости.**
3. Добавьте SHA-256 предыдущих `Game.locres` в `previousLocresHashes`; сохраняйте всю историю. `release.ps1` дополнит её из последнего опубликованного пакета при сборке.
4. Зафиксируйте изменения. В GitHub откройте **Actions → Publish translation → Run workflow**. Выпуск собирается и публикуется автоматически с номером из конфигурации. Либо используйте `release.ps1` локально с установленным и авторизованным GitHub CLI.

Чтобы пользователи получали обновление, выпуск должен быть обычным стабильным Release с файлом **translation.xml** и пометкой Latest. Черновики и предварительные выпуски не устанавливаются.

Для новой версии, меняющей шрифты или формат установки, также обновите миграцию в патчере и тесты. Пока история миграций охватывает изменения текстов при неизменных шрифтах.

## Состав

- `RussianPatcher.cs`, `Updater.cs` — интерфейс, установка и обновление.
- `UpdateTests.cs`, `CompatibilityTests.cs` — проверки обновлений и установки на непроверенные сборки; базовые проверки установки находятся в патчере.
- `translations.json` — редактируемые записи перевода.
- `build_translation.py` — компиляция UE locres и пакета обновления.
- `Fonts.pak` — переупакованные Roboto; см. `NOTICE.txt` и `Roboto-LICENSE.txt`.
- `Previous.locres` — предыдущая версия перевода для проверки миграции.

Anvil Empires принадлежит Siege Camp. Репозиторий не содержит основной архив игры или её исполняемые файлы.
