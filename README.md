## Установка

1. Закройте игру.
2. Распакуйте архив и запустите `AnvilRussian.exe`.
3. Выберите папку `Anvil Playtest`, нажмите **Установить / обновить**.
4. Запускайте игру через Steam.

## Обновления

При каждом запуске патчер проверяет последний стабильный GitHub Release. Для уже установленного перевода совместимое обновление скачивается и устанавливается автоматически, если игра закрыта. При первом запуске установка выполняется кнопкой. Есть отдельная кнопка проверки GitHub.

Для проверки обновлений запускайте **патчер**. Постоянного фонового сервиса нет; запуск игры непосредственно из Steam проверку не запускает.

Обновляется пакет перевода, а не программа-патчер. Проверяются версия, SHA-256 каждого файла, размер и отпечаток архива игры, SHA-256 игрового EXE. Пакет содержит только три вида ресурсов, пути установки заданы в программе. Неизвестная сборка игры отклоняется. При проблемах сети доступен встроенный перевод; уже загруженная и установленная версия сохраняется для работы без сети. При несовместимой игре ожидайте отдельного выпуска.

Обновление самой игры **не создаёт перевод автоматически**: автор должен проверить новую сборку, обновить строки и опубликовать совместимый выпуск. После изменения формата патчера новую программу потребуется скачать из Releases вручную.

Для удаления используйте кнопку **Удалить перевод**. Основной архив и EXE игры не изменяются. Изменённые вручную файлы локализации защищены от перезаписи. Источник обновлений — только Releases этого репозитория; независимая цифровая подпись пакетов пока не используется.

## Сборка и выпуск новой версии

Исходники сборки находятся в корне. Нужны Windows, Python 3 и .NET Framework 4.x (для игроков они отдельно не требуются).

```powershell
.\build.ps1
```

Результат — `dist/AnvilRussian.zip`, `dist/AnvilRussian.exe`, `dist/translation.xml`. Сборка проверяет подстановки и выполняет проверки установки, обновления, удаления, повреждённых пакетов и несовместимой игры.

1. В `translations.json` измените поле `russian`; сохраните `namespace`, `key`, исходный `source`, все `{0}` и теги разметки.
2. Увеличьте `version` в `release-config.json`. Для новой игры сначала заново извлеките и проверьте строки, затем обновите отпечатки игры. **Не меняйте отпечатки лишь для обхода проверки совместимости.**
3. Добавьте SHA-256 предыдущих `Game.locres` в `previousLocresHashes`; сохраняйте всю историю. `release.ps1` дополнит её из последнего опубликованного пакета при сборке.
4. Зафиксируйте изменения. В GitHub откройте **Actions → Publish translation → Run workflow**. Выпуск собирается и публикуется автоматически с номером из конфигурации. Либо используйте `release.ps1` локально с установленным и авторизованным GitHub CLI.

Чтобы пользователи получали обновление, выпуск должен быть обычным стабильным Release с файлом **translation.xml** и пометкой Latest. Черновики и предварительные выпуски не устанавливаются.

Для новой версии, меняющей шрифты или формат установки, также обновите миграцию в патчере и тесты. Пока история миграций охватывает изменения текстов при неизменных шрифтах.

## Состав

- `RussianPatcher.cs`, `Updater.cs` — интерфейс, установка и обновление.
- `UpdateTests.cs` — проверки обновлений; проверки установки находятся в патчере.
- `translations.json` — редактируемые записи перевода.
- `build_translation.py` — компиляция UE locres и пакета обновления.
- `Fonts.pak` — переупакованные Roboto; см. `NOTICE.txt` и `Roboto-LICENSE.txt`.
- `Previous.locres` — предыдущая версия перевода для проверки миграции.

Anvil Empires принадлежит Siege Camp. Репозиторий не содержит основной архив игры или её исполняемые файлы.
